# 🧮 Digital Calculator

यह एक साधारण और सुंदर डिजिटल कैलकुलेटर है, जिसकी मदद से यूज़र्स आसानी से जोड़, घटाव, गुणा और भाग जैसी बुनियादी गणितीय गणनाएँ (Calculations) कर सकते हैं.

## ✨ Features (मुख्य खूबियाँ)
* **Real-time Calculations:** बटन क्लिक करते ही तुरंत सटीक परिणाम दिखाता है.
* **Clean UI:** आँखों को सुकून देने वाला और सादा इंटरफ़ेस (User Interface).
* **Responsive Design:** मोबाइल और कंप्यूटर दोनों पर आसानी से इस्तेमाल किया जा सकता है.

## 🛠️ Tech Stack Used (किन तकनीकों का इस्तेमाल किया?)
* **HTML5:** कैलकुलेटर के बटन्स और स्क्रीन का ढांचा तैयार करने के लिए.
* **CSS3:** बटन्स के कलर्स, शैडो और लेआउट को सुंदर बनाने के लिए.
* **JavaScript:** कैलकुलेटर के पीछे की गणितीय वर्किंग और लॉजिक को चलाने के लिए.
